# FRC field audio

Unmodified WAV files from Team 254's Cheesy Arena field management system.
Source: https://github.com/Team254/cheesy-arena/tree/2c54d16a49f1c9d1169d2be1d1438eaf1757393c/static/audio

- start.wav: match start (cavalry charge)
- end.wav: AUTO and match end (buzzer)
- resume.wav: TELEOP start (three bells)
- warning.wav: END GAME warning
- shift_change.wav: period/shift change

Downloaded unchanged; bundled locally for simulator evaluation and practice.
