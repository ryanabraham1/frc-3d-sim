# Shooter drum audition sample

`shooter-drum.wav` is a 1.12-second, mono 24 kHz excerpt from Team 3255 SuperNURDs' real 2026 drum-shooter prototype test, for local sound evaluation.

- Video: https://www.youtube.com/watch?v=Cj_Z41wLZHQ
- Team's source post: https://www.chiefdelphi.com/t/frc-3255-supernurds-2026-build-thread/510269/151
- Original recording interval: 0.32–1.52 seconds.
- Processing: 80 Hz high-pass, 1800 Hz low-pass, normalization, and an 80 ms loop crossfade. No generated motor tones are mixed into it. Runtime playback ramps from half speed to normal speed and coasts down on release.

The hub-impact sounds are original Web Audio synthesis and remain separate from this recording.
